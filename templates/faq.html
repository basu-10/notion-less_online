Frequently Asked Questions

Everything you need to know to get started and make the most of NotionLess.

Getting Started

Click the Get Started button on the homepage or navigate to /app. On the login page, click Create an account. You'll need to provide a username and password. Your data will be stored in a separate SQLite file at userdata/<username>.db.

Yes. Your data is stored on the server in your own isolated SQLite database file. No data is shared with other users. Even on the hosted version, each user has an isolated SQLite database file at userdata/<username>.db.

Tip: Regularly export your data as JSON backup to avoid data loss.

You need an internet connection to use NotionLess Cloud. Your notes sync to the server so you can access them from any device. Once loaded, the editor is fast and responsive.

Basic Editing

Click the + button next to the page tree section in the sidebar. A new untitled page will be created and opened for immediate editing.

Type / on any empty line to open the slash command menu. You can type to filter commands. Common commands include:

/text — Plain text paragraph

/h1, /h2, /h3 — Headings

/bullet — Bullet list

/numbered — Numbered list

/todo — Checklist items

/quote — Block quote

/code — Code block

Tip: Press Enter to confirm or Esc to cancel.

Select the text you want to format and use keyboard shortcuts:

Ctrl+B — Bold

Ctrl+I — Italic

Ctrl+U — Underline

Ctrl+E — Inline code

Alt+Shift+5 — Strikethrough

Hover over any block to reveal the drag handle (⋮⋮) on the left side. Click and drag to reorder blocks within a page. This works for all block types including headings, lists, and paragraphs.

Organizing Pages

Hover over a page in the sidebar and click the + icon that appears. This creates a new child page nested under the current page. You can also drag pages to reparent them.

Double-click the page title in the sidebar to edit it inline. Press Enter to save or Esc to cancel.

Right-click (or long-press on mobile) on the page in the sidebar to open the context menu. Select Delete. Note: Deleted pages cannot be recovered.

Yes. Click the chevron (▼) next to any parent page to collapse or expand its children. This helps keep your page tree organized and reduces clutter.

Customization

Click the theme toggle in the sidebar footer or topbar. You can choose between:

Light — Clean light mode

Dark — Dark mode for low-light environments

Auto — Follows your system's preference (default)

Data Management

Click your username in the sidebar footer to open the profile menu. Select Export Data. This downloads a JSON file containing all your pages and settings. Keep this file safe as a backup.

Click your username in the sidebar footer and select Import Data. Choose a previously exported JSON file. The import will merge pages into your existing workspace.

Note: Importing does not delete existing pages. New pages from the backup are added.

Yes. Click your username in the sidebar footer and select Logout. Then log in with a different account. Each account has its own isolated SQLite database file and page tree.

Advanced Features

NotionLess supports multiple block types via slash commands:

Text: Paragraph, H1/H2/H3 headings, block quote

Lists: Bullet, numbered, to-do checkboxes

Media: Images (drag & drop or paste from clipboard)

Code: Code blocks with monospace font

Other: Dividers, tables

You can add images in two ways:

Drag and drop: Drag an image file directly onto the editor

Paste: Copy an image to your clipboard and paste it with Ctrl+V

Images are embedded as base64 data directly in the page content.
