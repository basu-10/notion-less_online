About this workspace

A local-first block editor built with BlockNote, served as static files. No backend, no build step, no account required.

Technology

  • BlockNote coreBlock-based editor (v0.51.3) via esm.sh CDN
  • IndexedDBBrowser-native persistence. Pages, titles, and blocks stored locally.
  • Vanilla JSNo framework overhead. ES modules, loaded from CDN.
  • CSS variablesTheming via theme.css. Light and dark modes follow system preference.

Project structure

  • app.htmlMain workspace — sidebar, tree, editor, settings panel
  • index.htmlLanding page
  • about.htmlThis page
  • css/theme.cssDesign tokens — accent color, shadows, radius, typography scale
  • css/app.cssLayout — sidebar, topbar, editor column, menus, dark mode
  • js/app-module.jsBlockNote initialization, IndexedDB CRUD, tree rendering, menus
  • components/Reusable HTML partials — brandbar, tree, topbar, menus

Hosting

  • python -m http.serverLocal development server
  • Cloudflare PagesDeploy the entire folder as a static site. No build command needed.
  • npx serveSimple static server via Node.js

Design

Soft neuromorphic monochrome: a single accent hue (#d85b45), paired soft shadows, gentle gradients, one neutral base tone. All tokens live in css/theme.css.
